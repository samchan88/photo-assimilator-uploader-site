Privacy Policy

Photo Assimilator Uploader · Last updated 16 September 2026

About Privacy Policy Support

Photo Assimilator Uploader is an Android companion for a user-controlled Photo Assimilator photo and video library. It reads photos and videos from device folders selected by the user and sends selected or new media directly to the Photo Assimilator server address configured by that user.

Developer and privacy contact

App: Photo Assimilator Uploader

Information the app accesses

  • Photos and videos available through Android MediaStore when permission is granted.
  • Media metadata needed to identify and transfer files, including filename, media type, size, timestamps, MediaStore identifier/URI and relative folder path.
  • A SHA-256 content hash calculated locally to determine whether the same file already exists on the configured Photo Assimilator server.
  • The Photo Assimilator server address configured by the user.
  • A dedicated Auto Upload device token issued by that Photo Assimilator server.
  • Local synchronization state such as selected folders, baseline timestamps/IDs, queue status, retry state and server-confirmed resumable-upload offsets.

The app does not read contacts, messages, call logs, installed-app inventory or precise device location.

How photos and videos are used

Photo and video access is the app's core functionality. The app uses broad media access so it can enumerate user-enabled MediaStore folders such as DCIM/Camera, establish a “new items from now on” baseline, find newly captured items during later syncs, and upload those items without requiring the user to manually pick the same folder contents every time.

The app does not modify or delete the source photo or video from the phone after upload.

Where media is sent

Media and related transfer metadata are sent only to the Photo Assimilator server address configured by the user. The uploader does not route photo or video content through a developer-operated cloud service.

If a user configures an http:// address, traffic is not encrypted in transit. HTTPS or a secure private network is recommended.

Device credential security

The uploader uses a dedicated, revocable Auto Upload device token rather than the Photo Assimilator Owner password. The token is encrypted on the Android device using Android Keystore-backed protection in the current implementation. The Photo Assimilator server stores a non-reversible verifier rather than the plaintext token.

Local storage and retention

The app stores configuration and synchronization state locally so it can remember selected folders, avoid unnecessary work and resume interrupted transfers. Clearing app data or uninstalling removes that local application state.

Successfully uploaded media remains on the configured Photo Assimilator server according to the user's own library and storage choices. Uninstalling the Android uploader does not delete copies already uploaded to that server.

Sharing, advertising and analytics

The current test builds contain no advertising SDK and no developer-operated analytics service. The developer does not sell photos, videos or uploader data.

Google Play may process information associated with downloading, installing and operating Play-distributed apps under Google's own terms and privacy policies.

Children's privacy

Photo Assimilator Uploader is a personal photo/video library administration and backup utility. It is not designed for or directed to children.

User choices and controls

  • Deny or change Android photo/video permissions in system settings.
  • Select which discovered folders are enabled.
  • Choose whether a newly enabled folder starts with “New items from now on” or includes existing items.
  • Revoke the uploader's dedicated device credential from Photo Assimilator.
  • Delete uploaded media from Photo Assimilator independently of the copy on the phone.

If Android grants only selected-media access rather than full media access, the uploader reports that complete selected-folder protection cannot be guaranteed.

Changes to this policy
